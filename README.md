# Design a Piano 🎹

A responsive, interactive piano keyboard UI built with clean HTML5 and modern CSS3 (featuring flexbox, CSS variables, pseudo-elements, and media queries). 

This project was developed as part of the **freeCodeCamp Responsive Web Design Certification** curriculum.

## 🚀 Live Demo
- **GitHub Repository**: [https://github.com/Regalson001/design-a-piano](https://github.Action/Regalson001/design-a-piano)

## ✨ Features
- **Semantic HTML5 Structure**: Organized key layouts divided into natural musical octaves.
- **Pure CSS Styling**: Custom key shapes, realistic layout positioning using `::after` pseudo-elements for black keys, and depth styling.
- **Responsive Web Design**: Integrated `@media` queries ensuring layout adaptation across varying viewport widths and mobile devices.
- **Box-Model Reset**: Implemented universal `box-sizing: inherit` patterns for reliable element sizing.

## 🛠️ Technologies Used
- **HTML5**
- **CSS3** (Flexbox, Media Queries, Pseudo-elements)
- **Git & GitHub** (Version Control)
